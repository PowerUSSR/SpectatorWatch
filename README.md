# SpectatorWatch

Плагин для Paper/Spigot 1.20 на сервере **VortexiaPolit**. Ваниль Minecraft полностью скрывает игроков в spectator-режиме от всех, кто сам не в spectator — этот плагин даёт персоналу возможность их видеть.

Каждые 10 тиков плагин сканирует онлайн-игроков; для тех, кто в `GameMode.SPECTATOR`, спавнит/двигает невидимый маркер (ArmorStand) с головой игрока (реальная текстура его скина) и именной табличкой `<ник> (spectator)`, с лёгким свечением (видно даже сквозь стены). Маркер показывается **только** игрокам с правом `spectatorwatch.see` — остальные его не видят.

## Право

`spectatorwatch.see` (по умолчанию: `false`, выдаётся вручную через права-плагин).

## Зависимости

Не требуются — использует только Bukkit/Paper API.

## Сборка

```
compile.bat
```

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
